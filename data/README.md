## Data Files

This project uses the following files:

| File | Description |
|------|-------------|
| `file1.csv` | Raw speeches dataset (322 commencement speeches) |
| `file2.csv` | Cleaned speeches with speaker/university metadata |
| `lemma.csv` | Lemmatized transcripts (output of notebook 01) |
| `data_dtm_lemma.csv` | Document-term matrix of lemmatized text (output of notebook 01) |
| `NRC-Emotion-Lexicon.csv` | NRC emotion lexicon — download from https://saifmohammad.com/WebPages/NRC-Emotion-Lexicon.htm |

Run the notebooks in order (01 → 02 → 03 → 04). 
Notebook 01 generates lemma.csv and data_dtm_lemma.csv from the raw files.
